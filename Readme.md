# ヴィジュアルタイマーアプリ

## 目的
経過時間を割合で表示するなど、時間の進捗をアニメーションで視覚的に表現する

## 現在の機能
1. 指定された要素をクリックすることで計測を開始
2. 経過時間に応じた進捗率の計算
3. 進捗率に応じたプログレスバーの更新
4. 計測終了時のインターバル停止

## ファイル構成
index.html - 表示用html
timer.js - 経過時間の計測、進捗率の計算を行い描画ファイル（現在はhourGlass.js）に値を渡す
hourGlass.js - 渡された値を使用して進捗率等を描画

## 今後の実装予定

- 複数の描画ファイルから表示方式を選択
- 一時停止・再開
